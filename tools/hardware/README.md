# Ferramentas de hardware

Esta pasta reune scripts de implementacao, revisao e validacao do projeto
KiCad. Os scripts de implementacao sao registros de migracoes pontuais e devem
ser usados apenas sobre a revisao para a qual foram escritos; o KiCad e a fonte
de verdade apos a migracao.

O projeto ativo esta em `../../hardware/kicad/estacao-meteorologica/`; os
relatorios de engenharia ficam em `../../docs/engineering/hardware/`.
