# Documentacao

- `tcc/fontes/`: documentos-fonte do texto academico.
- `tcc/assets/`: figuras selecionadas para o TCC.
- `tcc/entregaveis/`: versoes finais submetidas.
- `engineering/firmware/` e `engineering/hardware/`: planos, relatorios,
  validacoes, BOMs e registros tecnicos.
- `referencias/`: datasheets, artigos e notas de consulta relevantes.

Renderizacoes de verificacao e outras saidas temporarias pertencem a `../work/`.
