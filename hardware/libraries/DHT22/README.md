# Biblioteca local — DHT22 / AM2302

Esta biblioteca torna o sensor DHT22 usado no projeto portável:

- `DHT22.kicad_sym`: símbolo com a pinagem do encapsulamento SIP-4: 1=VDD, 2=DATA, 3=NC e 4=GND.
- `DHT22.pretty/DHT22_THT_P2.54mm_Vertical.kicad_mod`: footprint THT de 4 pinos, passo de 2,54 mm, compatível com o corpo do DHT22 utilizado no esquema.
- `DHT22.3dshapes/DHT22_THT_P2.54mm_Vertical.wrl`: representação mecânica simples do corpo do sensor para a visualização 3D. Não deve ser usada para validar interferências mecânicas críticas.

O componente de compra cadastrado no esquema é o AM2302 (nome comercial DHT22), Aosong, LCSC `C83988`.
