# Estacao meteorologica — TCC

Este repositorio separa as fontes do produto, a documentacao duradoura e as
ferramentas de apoio. Arquivos gerados localmente ficam em `work/` e nao fazem
parte do historico Git.

| Area | Conteudo |
| --- | --- |
| `firmware/` | Firmware STM32, gateway ESP32, testes e configuracoes do produto. |
| `hardware/` | Projeto KiCad, bibliotecas locais e pacotes de fabricacao por versao. |
| `docs/` | Material do TCC, referencias e registros de engenharia. |
| `tools/` | Scripts reprodutiveis para hardware, documentos e automacao. |
| `work/` | Caches, renderizacoes e resultados locais descartaveis. |

Consulte os READMEs de cada area antes de alterar caminhos ou executar scripts.
